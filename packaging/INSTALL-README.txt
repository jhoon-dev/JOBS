JOBS 0.1.0 Preview - Windows 64비트

설치 파일을 실행하고 설치 폴더를 선택하면 현재 사용자 계정에 설치됩니다.
관리자 권한, Qt, Python, Office를 별도로 설치할 필요가 없습니다.
시작 메뉴의 JOBS에서 실행하고 Windows 설정의 앱 목록에서 제거할 수 있습니다.
기본 경로: %LOCALAPPDATA%\Programs\JOBS

프로젝트 파일은 문서 폴더 등 사용자가 지정한 별도 경로에 저장하세요.
앱 제거는 설치 폴더 전체와 JOBS 설정·캐시·자동 복구 자료를 모두 지웁니다.
설치 폴더에 따로 넣은 파일도 삭제됩니다. 다른 위치에 저장한 프로젝트는 유지합니다.
다른 파일이 들어 있는 폴더에는 새 설치를 진행하지 않습니다.
업데이트나 제거 전에 실행 중인 JOBS 창을 닫아 주세요.

파일 메뉴에서 새로 만들기·열기·저장을 사용합니다. F9는 일정 계산입니다.
테스트 중인 preview이며 코드 서명과 자동 업데이트는 포함하지 않습니다.
전체 기능 사용법: https://github.com/jhoon-dev/JOBS
