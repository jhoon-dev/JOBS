# 작업 표·간트 중심 화면 계약

2026-10-29. UX-01~05를 구현 전에 정의한다. 기본 창은 프로젝트 제목/상태, 한 줄의 주요 명령, 검색·보기 설정, WBS/작업 표/간트, 접을 수 있는 진단으로 구성한다. 파일/편집/프로젝트/WBS/추적/자원/원가/보고서/복구/업데이트 메뉴와 기존 action objectName·단축키를 유지한다.

도구 모음은 새로 만들기·열기·저장, undo/redo, 작업 추가·선택 작업 편집, 일정 계산과 분석 진입을 우선한다. 선택 작업 편집은 기존 QAction을 공유해 읽기 전용/선택/상태일에 따른 사용 가능 상태와 저장/비동기 편집 경합 처리를 보존한다. 취소 명령은 작업 진행 중에 노출하고 진행 정보는 상태 표시줄에 둔다.

검색/필터/정렬/초기화는 표 바로 위에, WBS 표시 전환과 배율/기준선은 별도 보기 줄에 배치해 1024px에서 핵심 조작이 잘리지 않게 한다. WBS를 숨겨도 선택 범위를 초기화하지 않으며 보기 줄에 범위를 표시한다. 표/간트의 행과 헤더 높이를 공유하고 기본 폭은 splitter로 조절한다.

프로젝트 제목은 plain text로 표시한다. 파일 경로·revision·휴일·실적 이력 등은 메타데이터 툴팁으로 옮기고 읽기 전용/복구/이전 형식/이력 제한은 화면에 유지한다. 계산 상세는 접혀 있어도 요약과 진단 존재를 안내하며 오류는 자동으로 펼친다. 입력 설명은 상시 문단 대신 F1 도움말로 제공한다. 문서가 없을 때 새로 만들기/열기 진입과 안내를 제공한다.

이번 단계는 화면 구성과 탐색 개선이다. 사용자 데이터·계산 정책·저장 형식·보고 내용과 기존 worker/증분 갱신을 바꾸지 않는다. 전역 강제 테마 대신 네이티브 팔레트와 포커스/선택/비활성 상태를 유지하면서 간격·선·강조색을 정돈한다. 실제 Qt 캡처와 작은 창 회귀로 기능 접근성과 작업 영역을 확인한다.
