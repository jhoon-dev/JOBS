# 화면과 사용자 흐름
상태: 화면 상세 PROPOSED. Windows/macOS 설치형은 사용자 확정, C++ + Qt 기본 방향은 사용자 위임에 따른 ADR-008 결정이다. 시각 디자인·세부 Qt 모듈/버전은 미확정.

## 첫 입력
프로젝트명→시작일→기본 근무 주/휴일 확인→작업명 목록 붙여넣기→초안 생성.
기간이 없으면 미산정 상태로 두고 완료일을 확정값처럼 표시하지 않는다. '1일' 입력 시 적용 달력과 시간 환산을 확인할 수 있어야 한다.
쉬운 입력은 고급 계산 규칙을 숨겨 오류를 만드는 방식이 아니다. 기본 정책 요약과 미설정 항목을 항상 확인할 수 있게 한다.

## 주 작업 화면
왼쪽 WBS/프로젝트 탐색, 중앙 작업 표와 간트, 선택 작업의 우측 상세, 하단 계산 진단/변경 영향 패널을 기본안으로 제안한다.
표 열은 이름·기간·시작·완료·선행·자원·진척·편차를 기본으로 하고 사용자 정의 가능하게 한다. 실행 취소·다시 실행과 저장/계산 상태를 분리 표시한다.
간트 드래그는 실제 날짜 변경인지 제약 생성인지 먼저 정책으로 정의하고 변경 미리보기로 설명한다.

## 주요 흐름
1. 계획 작성: WBS 편집→기간/달력→의존관계→계산→순환/충돌 해결→승인.
2. 기준선: 계산 입력·결과 확인→명칭·사유→승인→읽기 전용 스냅샷.
3. 실적 보고: 상태일 선택→실제 날짜·완료 작업량·잔여량 입력→불일치 확인→재예측→기준선 편차.
4. 자원: 자원 사전→가용량→배정→히스토그램 과부하→조정 시나리오→비교→선택 반영.
5. 교환: 파일 형식·버전 선택→매핑 미리보기→지원/손실 목록→확인→가져온 버전과 원본 참조 보존.
6. 협업: 담당자가 실적 제출→검토자 승인/반려→현재 계획에 반영→감사 이력.
7. 복구: 변경 이력 선택→영향 확인→새 버전으로 복구. 과거 기록 삭제와 구분한다.

## 화면 목록과 빈/오류 상태
프로젝트 홈, 일정 편집, 네트워크, 달력, 자원/배정, 기준선 비교, 실적 입력, 원가/성과, 위험/이슈, 포트폴리오, 보고/출력, 교환 센터, 관리/감사.
초기 빈 상태는 입력 예시를 제공하되 가상 데이터를 실제 계획처럼 저장하지 않는다. 미계산·실패·오래된 계산 결과를 구분한다. 권한 부족·동시 편집 충돌·가져오기 손실에 재시도/검토 경로를 제공한다.
키보드 탐색, 대용량 표 가상화, 스크린리더 읽기 순서와 색각 대응을 화면별 수용조건에 포함한다.


파일 기본 흐름은 새로 만들기→프로젝트 입력→저장→닫기/열기, 다른 이름 저장→독립파일, OS간 파일 이동→열기다. 계정·서버 없이 수행하며 FILE-T01~09를 적용한다. SaveAs 문서ID·첨부/외부참조·복구·잠금/동기화충돌 계약은15문서에 있다.
