## ADR-P06 언어·UI 선택 평가 제안
상태 SUPERSEDED_BY_ADR_008. 당시 사용자는 C#, Rust, C++ 후보를 질문했으며 특정 기술을 선택하지 않았다. C++/Qt는 잠정 우선 후보, C#/Avalonia는 팀 생산성 중심 대안, Rust는 계산 코어 또는 별도 GUI 생태계 검토 후보로 둔다. 이는 벤치마크 결과가 아니다.
Qt와 Avalonia를 같은 WBS·간트·편집 명령·계산 fixture·OS 환경에서 ARCH-G0~G6으로 비교한 뒤 확정한다. 팀 역량과 라이선스·운영 비용을 포함한다. 정확성·복구·접근성 실패를 평균점수로 상쇄하지 않는다.
초기에는 한 주 언어와 명확한 모듈 경계를 사용하는 안을 제안한다. 처음부터 C++/C#/Rust를 혼합하지 않는다. Rust 코어와 FFI/IPC 등 다중 언어는 메모리 안전성·격리·성능 이익이 직렬화·도구체인·디버깅·배포 비용을 넘는다는 근거가 생길 때 별도 ADR로 평가한다. 코드 프로토타입은 현재 문서 작업에 포함하지 않는다.

## ADR-008 C++ + Qt 기본 방향 선택
상태 DECIDED_DIRECTION. 사용자가 최적 방향 결정을 dot에게 위임했고 dot은 C++ + Qt, UI 독립 C++ 계산 코어, 로컬 저장·자동 복구를 선택했다. ADR-P06의 후보 미결정 상태는 이 결정으로 대체한다. C#/Rust는 초기 혼합하지 않고 게이트 실패 시 재검토 대안으로 보존한다. 성능 최적 입증은 아니다.
세부 Qt 모듈/버전/라이선스·파일 형식·DB는 검토 후 확정한다. 14-cpp-qt-architecture.md의 의존·파일/복구 계약과 재검토 게이트를 적용한다. 구매·약관동의·인증서 발급·배포·권한변경·구현은 이번 단계에 포함되지 않는다.
