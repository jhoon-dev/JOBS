## 기능행 연결과 해결증거 상태
09-source-traceability.json이 기능행↔확인과제의 정규 다대다 추적 데이터다. namespace 포함 open_question_id, 양방향 row ID, blocking_scope와 해결증거 상태를 보존한다. 현재 연결은 주제 제안(PROPOSED_TOPIC_MAPPING), 모든 해결증거는 NOT_PROVIDED다. 새 관계를 판단하지 못하면 UNMAPPED이며 관련 없음으로 확정하지 않는다. 현재39개 모두 최소 하나의 제안 주제 연결이 있으나 관계의 정밀성·누락·과잉은 행별 검토 전이다. 과제 해결에는 원문에서 지정한 실제 증거가 필요하다.
