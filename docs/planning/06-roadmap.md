# 단계별 로드맵
단계는 기능 제외가 아니라 개발 순서다. 일정/인원/예산 추정은 아직 하지 않는다.

|---|---|---|---|
| A 요구·계산 기반 | 카탈로그 전행 매핑, 용어, 달력/네트워크 계약, 검증 fixture 설계 | 원문 접근·계산 전문 검토 | 337행 보존 대조, 미결 정책 목록, 수동 기대값 승인 |

## 다음 작업 순서
1. 공식 카탈로그를 소비자 로컬에 확보하고 전행 출처·39개 확인과제를 보존한다.
2. 별도 계산 전문 검토를 이 초안과 대조하여 모순·정책 결정을 ADR로 기록한다.
3. 첫 사용 산업·프로젝트 규모·제품군 우선순위를 사용자와 정한다.
4. 플랫폼/저장/동기화/배포 대안을 평가한 뒤 기술 설계에 착수한다.
5. 구현 승인 후 계산 fixture와 수용조건을 먼저 고정하고 작은 수직 기능을 만든다.

## 진행 관리
주간 상태는 완료 증거·진행 항목·차단·결정 필요·다음 검증으로 기록한다. 완료는 산출물과 재현 가능한 검증 근거가 있는 경우다.
요구 변경은 원문 행과 JOBS ID의 영향을 기록한다. 범위가 커지면 단계와 의존관계를 조정하고 후보를 조용히 삭제하지 않는다.

## 최신 목표와 데스크톱 반영
Windows/macOS 데스크톱 방향은 확정이며 ADR-008에 따라 C++ + Qt 기본 방향을 선택했다. 세부 Qt 모듈/버전/라이선스는 미정이다. 단계 A에서 로컬 파일/복구/이관 계약과 OS 평가 계획, B에서 오프라인 수직 흐름과 파일 충돌, C 이후 선택 협업 확장을 다룬다. F에서는 OS별 설치·업데이트·복구·접근성 검증을 수행한다. 현재 실행·배포 승인은 아니다.
모든 단계에 Parity와 Superiority 결과를 별도로 남긴다. PRD의 SUP-01~05와 DESK-01~09를 단계별 수용조건에 연결한다. 전체 기능 후보는 유지한다.



ADR-008 기본 방향에 따라 세부 Qt 모듈/버전/라이선스 확정과 구현 검증을 위한 ARCH-G0~G6(13-desktop-options.md)을 평가한다. A에서 프로토콜·파일/계산 경계를 설계하고, 향후 구현 승인 후에만 G1~G5 실측·복구·접근성·설치 검증을 수행한다. 기획 v0.1은 현재 자료 통합까지이며 추가 기능 연구로 범위를 계속 늘리지 않는다.

갱신: 기본 언어/UI 방향은 사용자 위임에 따른 C++ + Qt로 선택됐다. A에서 ADR-008의 UI/코어·파일/복구 계약을 검토하고, 향후 구현 승인 후 필수 게이트 증거를 확보한다. 후보 비교는 선택 전제로 반복하는 절차가 아니라 세부안 검증과 실패 시 재검토 경로다.

최우선 PRD-08: A에서 자체 파일 전달·복구·잠금·이관 계약, B에서 계정/서버 없는 새로 만들기→열기→저장→다른 이름→OS간 전달 흐름을 검증한다. 외부제품 교환과 협업은 별도 단계이며 후보를 제거하지 않는다.

REQ-ORA-098 분리: B의 J-03 결정론적 달력 기반과 D-E의 J-11 확률 날씨/비근무 모델을 따로 검증한다. 분포·상관·seed·수렴·quantile이 미검증이면 확률 기능을 완료 처리하지 않는다.

## 2026-10-26 다음 실행 증분

기초 일정·공수/달력·수동 분할·자원·원가/추적·보고·저장/복구 구현 후, 사용자 요청에 따라 PRD를 먼저 구체화하고 PERF-01~04 통합 검증·대용량 반응성을 진행한다. 순서는 고정 입력/측정 도구→병목 전후 측정과 개선→진행/취소→운영 흐름 통합 회귀→Windows/macOS 검증이다. 초기 기획의 미승인/미실행 표기는 당시 기록이며 이번 요청 범위의 착수 승인을 대체하지 않는다. 편집 UX·외부 교환·자원 고도화·다중 프로젝트·배포는 별도 후속 증분으로 남긴다.


이 증분의 로컬 구현·측정 결과는 [성능·통합 검증 증거](../performance-integration.md)에 기록했다. 계산 진행/취소·재시작·session 보호, 1천/1만 고정 입력 측정, 화면 주변 간트와 전체 결과 동등성, 운영 흐름 통합 회귀를 구현했다. 후속 편집 UX와 외부 교환은 PRD의 수용조건을 먼저 구체화한 뒤 진행한다. 측정 범위를 제품 전체 성능/동등성 완료로 확대하지 않는다.


## 2026-10-26 작업 편집 UX 착수

사용자 요청으로 EDIT-01~05를 PRD에 먼저 반영하고 삽입/삭제/복제·다중 선택·원자적 TSV 붙여넣기·검색/필터/정렬·키보드를 구현한다. 이후 도메인/네이티브 UI·저장/복구·Windows/macOS 회귀를 검증한다. 모델 전환/자동 행 확장은 별도 후속 범위이며 기존 전체 기능 후보를 유지한다.
