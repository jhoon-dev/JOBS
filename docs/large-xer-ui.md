# 1만 작업 XER·앱 아이콘·화면 크기 계약

2026-10-30. SCALEUI-01~05를 구현 전에 확정한다. 실제 앱에서 10,000개 작업 XER을 불러와 계산/간트를 확인하고, 독립 native Qt fixture에서 동일 경로의 시간을 계측한다. 외부 UI 자동화 도구의 요청/대기 시간은 성능 수치에 포함하지 않는다.

합성 계획은 동/층/공종/단계의 WBS, FS/SS/FF 관계, 마일스톤, 작업 달력·예외일, 자원 배정을 포함한다. 날짜 범위가 불필요하게 수십 년으로 늘어나지 않도록 공구/층을 병행하고 단계 인계를 연결한다. 원본 XER과 변환 진단을 보존한다. 기간 기반 결과이며 P6 독립 재계산 일치나 자원 평준화가 확인된 결과로 설명하지 않는다.

측정은 importer 해석과 교환 파일 게시/문서 열기, MainWindow 준비·표시, 실제 F9 비동기 계산과 최종 간트 갱신, 위치를 바꾼 반복 스크롤/선택과 강제 viewport repaint로 나눈다. 표본·p50/p95/max, 이벤트 루프 heartbeat, 실행 환경과 원본 checksum을 남긴다. 한 기기의 유한 측정이며 전체 입력/하드웨어에서의 응답성을 보증하지 않는다.

아이콘은 Store의 기존 SVG를 공통 원본으로 사용한다. PNG/ICO/ICNS를 저장소의 재현 가능한 렌더러로 만들고 Qt resource, EXE resource, bundle, 설치/제거기에 연결한다. 아이콘 때문에 런타임 SVG 플러그인이나 네트워크 의존성을 추가하지 않는다.

행/헤더는 표와 간트의 공유 규격을 WBS에도 적용한다. 한 줄 컨트롤은 현재 폰트 메트릭과 최소 논리 높이를 기준으로 맞춘다. 배율은 테스트 프로세스의 QT_SCALE_FACTOR로 지정하며 사용자의 Windows 설정을 바꾸지 않는다. 일반 대화상자에 불필요한 전역 콤보박스 스타일을 적용하지 않고 작은 창에서도 기본 명령과 최소 작업 행을 유지한다.

1만 작업 수용 보완: 활동 TASK는 10,000개로 유지하며, 한 작업에 여러 선행/자원이 연결되는 TASKPRED·TASKRSRC는 각각 100,000행으로 구분한다. 파일 16MiB와 parser 전체 행 수 및 원래 도메인/교환 검증을 유지한다. 원본 fixture의 10,999개 관계·12,000개 배정은 유지하고 이 수용/상한 회귀를 추가한다.
