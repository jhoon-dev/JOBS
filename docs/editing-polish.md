# 편집 흐름·성능·P6 corpus 개선 계약

2026-10-30, POLISH-01~09. 구현 전에 요구사항과 수용 범위를 정의한다.

macOS 검색 줄의 정렬 실패는 높은 배율에서도 실제 위젯 사각형이 일치하도록 네이티브 스타일의 layout inset과 배치를 고쳐 해결한다. 측정치와 스크린샷을 실패 전에도 남긴다. 종전 1px 허용을 더 키우지 않는다.

성능은 기존 1만 작업 XER과 기존 독립 native probe를 기준으로 변경 전후 여러 프로세스에서 측정한다. 최초 표시/선택, 계산 worker와 GUI 반영, 32회 위치 이동을 구분한다. 전체 PlanInput/결과 캐시의 수명은 문서 세대에 묶고 편집·닫기·취소·오래된 결과 차단을 유지한다. 간트는 화면 주변 행만 그리되 선택/스크롤마다 전체 행을 다시 인덱싱하지 않는다.

새 탐색 명령은 보기에만 영향을 준다. 선택 시 가로 화면 밖의 작업 시작/마일스톤을 보이게 하고 명시적인 선택 보기에서는 날짜 구간을 가운데 배치한다. 전체 일정 맞춤은 현재 필터/WBS에 표시된 작업과 표시 기준선을 포함한다. 유효하지 않은 계산·빈 범위에서는 명령을 비활성화한다. 작업 유형·날짜·문서 dirty·undo를 변경하지 않는다. 일/주 및 맞춤 배율에서 날짜/드래그 좌표 변환은 같은 기준을 사용한다.

상세 편집은 공통 helper를 사용해 주요 단일 줄 입력을 같은 높이로 정리한다. label buddy, 폼 간격, 최소 버튼 높이, 여러 줄 입력의 가변 영역을 제공한다. 기존 인라인 오류가 있는 화면은 이를 유지하고, 모달 오류만 있는 주요 화면은 초안 가까이 오류와 수정 포커스를 제공한다. 계산/확정·취소와 읽기 전용 의미는 유지한다.

외부 표본은 공개 업스트림 테스트 자료 중 P6 내보내기 표본과 그 이용 조건을 확인해 선택한다. 원본은 변경하지 않고 원본 checksum, 출처 commit, header version/encoding과 한계를 기록한다. 기본 빌드/앱은 네트워크·Java에 의존하지 않으며 외부 corpus 검사만 MPXJ를 사용한다. 지원/손실 투영/거부/독립 reader 결과를 구분한 기계 판독 행렬을 남긴다. corpus 통과는 P6 전체 기능이나 재계산 동등성을 입증하지 않는다.
