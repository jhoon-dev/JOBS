# WBS·표·간트의 첫 연결

2026-10-26 · PRD-02 일부, J-01, F11에 해당한다.
WBS는 보고·집계 트리이며 실행 작업과 선행관계 그래프는 별도로 유지한다.
전문 PM 전체 기능과 성능 우월성은 이후 시나리오로 검증한다.

## 사용 흐름

1. 새 프로젝트에 작업 목록을 입력한다.
2. 왼쪽 프로젝트 루트를 선택하고 **WBS 추가**로 그룹을 만든다. 그룹을 선택하여 추가하면 하위 그룹이 된다.
3. 프로젝트 루트에서 표의 작업을 선택하고 **선택 작업의 WBS 변경**에서 소속을 지정한다.
4. 그룹을 선택하면 하위 그룹을 포함한 작업을 표·간트에 표시한다. 그룹 선택 상태에서 작업 추가 시 그 그룹에 배치한다.
5. **WBS 이동**으로 부모를 변경하거나 이름을 바꾼다. 자식/소속 작업이 없는 그룹만 **빈 WBS 삭제**로 지울 수 있다.
6. 기간·FS 선행·휴일을 입력하고 F9로 전체 프로젝트를 계산한다. 간트 막대와 표는 같은 stable ID를 가리킨다.
7. 표에서 행을 선택하거나 간트의 막대/라벨을 클릭하면 같은 작업을 강조한다. 간트 배율은 일/주로 바꾼다.

WBS 필터 상태에서도 표 왼쪽 행 번호와 선행 입력은 **프로젝트 전체의 원래 행 번호**다.
예를 들어 2번 작업만 보이더라도 선행 1은 전체 프로젝트의 1번 작업이다.
파일에는 행 번호 대신 ID를 저장한다. 필터 밖 선행도 전체 계산에 포함하며,
간트 tooltip에 화면 밖 선행 개수를 보여준다. 두 작업이 함께 보일 때 연결선을 그린다.

## 데이터·집계 계약

WbsNode는 `id`, `name`, `parentId`, Task는 `wbsId`를 갖는다. 빈 ID 참조는 프로젝트 루트/미분류다.
WBS와 작업의 ID는 구분하며, 중복 ID·누락 부모·누락 소속·자기/하위 그룹으로의 순환 이동을 거절한다.
실패한 편집은 문서와 revision을 유지한다. 정상 변경은 revision을 올리고 기존 계산을 STALE 처리한다.
그룹 간 이동은 작업 ID·기간·선행 ID를 바꾸지 않으며 재계산 결과도 같아야 한다.

선택 범위 집계는 하위 WBS의 고유 실행 작업을 각각 한 번 포함한다.
표시하는 기간 합계는 **알려진 작업 기간의 합계**이고, 미정 개수를 별도로 표시한다.
병렬 작업 때문에 이 합계와 그룹의 시작~완료 경과기간은 다를 수 있다.
최신 유효한 전체 결과에서만 하위 작업의 최소 시작·최대 완료를 집계한다.
빈 그룹·미계산·충돌·오래된 결과에는 확정적인 그룹 날짜를 붙이지 않는다.
WBS 자체에 기간이나 실행 선행관계를 자동 생성하지 않는다.

## 간트 의미

간트는 읽기 전용으로 계산 엔진의 현지 civil start/finish를 실제 날짜 축에 배치한다.
음영은 주말·하루 전체 휴일이며, 막대는 시작~완료의 경과 구간이다. 휴무일의 자원 배정을 뜻하지 않는다.
빨강과 `[임계]` 텍스트는 임계 작업, 파랑은 여유 작업, ◆는 0기간 마일스톤이다.
FS0 연결선과 화살표는 stable ID 관계를 표시한다. 아주 짧은 작업도 선택하도록 최소 표시 폭 3px를 쓴다.
tooltip에서 정확한 분 단위 시작·완료와 ID를 확인한다.

배율 변경은 계산 입력을 바꾸지 않는다. 표·간트는 같은 필터 순서/행 높이/수직 스크롤을 사용한다.
수직 스크롤 중 날짜 머리글은 고정한다. 미정·충돌·STALE 결과의 막대는 숨긴다.
날짜 드래그 정책·제약 생성·변경 미리보기가 아직 정해지지 않았으므로 간트 편집은 후속 범위다.

## 파일과 검증

WBS 최초 구현은 schema 3이며, 현재 schema 4는 WBS에 기준선·실적 원장을 함께 포함한다.
schema 1/2를 열면 새 필드를 빈 계층/미분류로 채우고 기존 ID·revision·기간·관계를 유지한다.
저장 시 새 이름으로 현재 schema 사본을 만들며 이전 원본 bytes를 보존한다.

`wbs_contract`: F11(A8h/B16h)의 그룹 합계 8/16→24/0, 전체 24h, ID/그래프/일정 불변,
중첩 그룹 이동·중복 집계 방지·미정/빈 집계·순환/누락 거절·읽기 전용·깊이 2천 탐색을 검사한다.
`file_lifecycle`: 계층/소속 왕복, schema 1/2 원본 보존 사본 저장, checksum이 맞아도 순환 계층 거절.
`wbs_gantt_ui`: 필터 상태의 편집 대상, ID 선택 연동, 그룹/작업 이동, 막대/마일스톤/FS 링크,
숨겨진 외부 선행 안내, 배율·스크롤·STALE 표시를 검사한다.

아직 WBS 코드 체계·작업 순서 이동·다중 선택·undo/redo·요약 작업의 실행 링크·접기와 간트 요약행,
네트워크 뷰 및 대용량 가상화/접근성 전반은 후속 범위다.
기준선 겹침 표시·실적 반영 예측·변경 비교는 [기준선·실적 계약](baseline-progress.md)에 따라 추가했다.
