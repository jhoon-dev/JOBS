# 자원 단가 · 작업 비용 · 실제원가 · EVM

2026-10-26 사용자 요청 구현. J-09/J-10의 첫 흐름이며 전체 회계·세금·환율·상용 도구 호환성 완료를 뜻하지 않는다.

## 사용 순서

1. 작업 기간·FS·자원을 등록하고 작업별 배정률을 지정한다.
2. **원가 → 통화·자원 단가**에서 프로젝트 통화를 먼저 설정한다. 기본 KRW, 선택 KRW/JPY/USD/EUR. 단가·예산·실제원가·기준선/시나리오의 원가 입력이 생기면 통화 재해석을 거절한다. 환산 기능은 없다.
3. 자원별 단가를 `2026-10-26=10000`, `2026-11-01=12000`, `2027-01-01=?`처럼 한 줄씩 입력하고 저장한다. 자원 100%의 **1근무시간당** 금액이다. KRW/JPY는 정수, USD/EUR는 소수 2자리까지 사용한다. 중복 유효일·음수·지원 정밀도 초과는 거절한다.
4. 작업을 선택하고 **선택 작업 예산**에서 추가 고정비와 발생 방식(시작/근무기간 균등/완료), 성과 측정법(물리 진척 또는 완료 0/100)을 설정한다. 고정비 없음은 `0`으로 확인하고, 공란은 미정으로 둔다.
5. 기간·선행 오류가 없는 현재 계획을 **기준선 저장**으로 승인한다. 단가·통화·배정·고정비·발생/성과 측정법도 동결된다. 이후 입력 변경은 새 기준선에만 반영된다.
6. **상태일 설정** 후 작업별 **원가·물리 진척 보고**에서 그때까지의 누적 실제원가와 물리 진척률(0~100%, 소수 2자리)을 입력한다. 보고자·사유는 필수다. 공란은 미정, 0은 확인된 0이다. 이전 값이 채워지며, 정정도 새 기록을 추가한다.
7. **원가·EVM 분석**에서 기준선과 EAC 가정을 선택한다. 작업별 비용/EVM, 프로젝트/WBS 집계, 일별 금액, PV·EV·AC 추이를 확인한다. 셀 설명에는 작업/보고 ID·출처·보고자·사유를 표시한다.
8. `.jobs` 파일에 저장한다. 재열어도 단가·작업 설정·불변 기준선·원가 보고와 정정 이력이 보존된다. EAC 산식 선택은 조회 옵션이며 다시 열면 기본 가정으로 시작한다.

## 계획원가와 실제원가

정책 ID는 `cost-day-minor-half-up-v1`이다. 계획과 기준선에 보존하며 다른 정책을 조용히 대체하지 않는다.

- 작업 계획원가 = 배정별 자원비 + 추가 고정비. 기간 고정 정률 배정이며 기간/생산성을 단가로 변경하지 않는다.
- 유효일 이전 구간에는 이전 단가를 사용한다. 해당 근무일 이전/당일 단가 중 가장 최근 항목을 적용한다. 미정 항목은 다음 유효 단가까지 계속 미정이다. 첫 유효일 이전 가격을 0으로 추정하지 않는다.
- 자원비 = 근무분 × 배정률(%) × 시간당 단가 / 6,000. 근무달력의 실제 근무구간만 포함한다. 인시와 장비시를 직접 합하지 않고, 각 자원의 단가로 계산한 동일 통화 금액을 합한다.
- 배정·근무일마다 최소 통화단위로 half-up 반올림한 후 합산한다. 전체를 마지막에 한 번 반올림하는 정책과 다를 수 있다.
- 고정비 균등 발생은 `round(고정비 × 누적 근무분 / 총 근무분)`의 차이를 날짜별로 배분하여 전체 합을 보존한다. 시작/완료 방식은 해당 시각에 전액 발생한다. 0기간 고정비는 균등/완료 방식일 때 마일스톤 시각에 발생한다.
- 수치 저장과 계획/EV 계산은 정수 최소 통화단위다. 단가는 시간당 최대 1,000,000,000 최소 단위, 작업 금액/합계 한도는 9,000,000,000,000 최소 단위다. 계산/집계 한도를 넘으면 값은 미정과 진단으로 반환하며 넘친 정수를 정상 금액으로 표시하지 않는다.
- 누락 단가·미정 고정비·불완전 일정은 금액 누락 원인이다. 알려진 일부만 전체 합계로 표시하지 않는다. 앞선 일별 금액이 미정이어도 별도로 계산 가능한 이후 일별 금액은 유지한다. 누적 금액은 누락 구간이 있으면 계속 미정이다.
- **AC는 수동 누적 보고 원장**이다. 실제 소요 기간 × 현재 단가로 만들지 않는다. 새 단가·배정·계획 편집은 과거 실제원가를 재평가하지 않는다. 실제 자원별 작업시간/전표별 비용의 자동 산정은 후속 범위다.

원가 보고는 작업 ID, 상태일, 누적 실제원가, 물리 진척 basis points, 통화, 보고자·사유, UTC 기록시각, 원본 문서/revision, 이전 보고 ID를 저장한다. 보고 원장과 기존 일정 실적 원장은 각각 원가/물리 성과와 실제 날짜/소요·잔여를 담당한다. 상태일 이전/당일 보고 중 가장 최근 보고일을 선택하고 같은 보고일은 나중에 추가한 정정이 우선한다. 과거일 보고가 나중에 추가되어도 더 최근 보고일을 덮어쓰지 않는다. 누적액 감소도 정정 사유와 이력을 남기며 허용한다. 공란 필드는 이전 값을 암묵적으로 이어받지 않고 미정으로 기록한다.

## EVM 정의와 집계 범위

| 지표 | 정의/조건 |
|---|---|
| BAC | 선택 기준선 입력·유효일 단가·배정·고정비의 전체 예산 |
| PV | 기준선 달력·동결 일정·비용 발생 방식으로 상태 시각까지 계획된 누적 금액 |
| EV · 물리 진척 | BAC × 상태일 기준 보고된 물리 진척률. 기간 진척으로 대체하지 않음 |
| EV · 완료 0/100 | 상태일 기준 일정 실적 보고가 있을 때 미완료=0, 실제 완료 보고=전체 BAC. 보고 자체가 없으면 미정 |
| AC | 상태일 기준 누적 실제원가 보고값 |
| CV / SV | EV−AC / EV−PV. SV는 금액이며 날짜 지연 시간이 아님 |
| CPI / SPI | EV/AC / EV/PV. 분모 0 또는 근거 누락이면 미정 |

BAC 0이 명시된 작업의 EV는 0이다. 물리 진척은 독립 관측치이며 100%를 보고해도 실제 완료일이나 잔여 기간을 자동 변경하지 않는다. 실제 완료가 있어도 물리 진척 방식의 EV를 임의로 100%로 대체하지 않는다. 선택 기준선에 고정된 측정법을 따른다.

현재 계획/실제 총계는 현재 작업 ID 범위, EVM 총계는 **선택 기준선 작업 ID 범위**다. 기준선 밖 추가 작업의 계획·AC는 현재 총계에 나타나며 EVM 코호트에는 넣지 않는다. 기준선 밖/누락 작업을 드러내며, 필요한 근거가 없으면 관련 총계/비율을 미정으로 유지한다. 범위 변경의 타당성은 새 승인 기준선으로 관리한다. 선택 기준선과 현재 통화가 다르면 환산 없이 EVM을 산정하지 않는다.

WBS는 현재 구조의 계획/실제와 기준선 구조의 EVM을 별도 행으로 표시한다. 하위 작업을 고유 ID로 한 번씩 집계하고, 프로젝트 총계를 WBS 합계의 재합산으로 만들지 않는다. 상위/하위 행을 다시 더하면 중복이다. CPI/SPI는 **합계 EV/합계 AC 또는 PV**이며 작업별 비율의 평균이 아니다.

## EAC/ETC 가정

| 산식 ID | 가정과 계산 |
|---|---|
| `budget-remaining-v1` (기본) | 잔여 작업은 원래 예산대로: ETC=BAC−EV, EAC=AC+ETC |
| `cpi-v1` | 원가 효율 지속: ETC=(BAC−EV)/CPI, EAC=AC+ETC (=BAC/CPI) |
| `cpi-spi-v1` | 원가/일정 금액 효율 모두 지속: ETC=(BAC−EV)/(CPI×SPI), EAC=AC+ETC |

필요한 BAC/EV/AC와 양의 지수가 없으면 미정이다. 예측 금액은 부동소수 확장 정밀도로 산정하여 최소 통화단위로 반올림하며, 산식/가정을 화면과 분석 데이터에 명시한다. 공수 기반 bottom-up ETC, 수동 EAC 승인, TCPI·확률 원가 예측은 후속 범위다.

일별 표는 일별 현재 계획/기준선 예산과 누적 PV/EV/AC다. 근무일과 보고일을 표시한다. PV 추이는 미래 기준선 계획을 포함하며 상태일 당일은 상태 시각의 값이다. EV/AC는 상태일 이후를 예측하지 않고, 미보고 구간을 0이나 선형 보간으로 채우지 않는다. AC는 보고된 누적액이므로 지출 발생일별 원장으로 해석하지 않는다. 추이의 선은 알려진 인접 표본을 연결한 참고 표현이다.

## 파일·검증과 후속 범위

schema 6은 resource.rates, currency/costProfile/taskCosts 및 costEntries를 포함한다. 단가/작업 비용은 기준선·평준화 시나리오의 입력 사본에도 보존한다. 시나리오의 원가 비교/적용은 이번 화면의 범위가 아니다. 기존 schema 1~5는 비용 미정·빈 원장으로 읽고 다른 이름 저장으로 schema 6 사본을 만든다. 이전 파일에 비용 0을 임의 생성하지 않으며 원본 bytes를 유지한다. 사본은 기존 원가 보고의 원본 문서/revision을 재작성하지 않는다.

계산은 UI 밖 불변 스냅샷에서 수행하고 세대 번호·문서 ID/revision으로 오래된 결과를 거절한다. 입력 대화상자에서도 변경된 문서를 거절한다. 읽기 전용은 단가 조회/EVM 분석만 허용한다. UI는 저장/재열기·정정 이력을 지원하며 회계 전표·세금·외화 환산·단가 종류/초과근무·자재 비용·원장 가져오기/보고서 내보내기·상용 원가 호환성은 후속 범위다.

F10 기대값: 16h 작업에 균등 고정비 1,000, 상태일이 첫 8h 완료 시각, 물리 진척 40%, AC 600이면 BAC 1,000 / PV 500 / EV 400 / AC 600 / CV −200 / SV −100 / CPI 2/3 / SPI 0.8이다. EAC는 예산 유지 1,200, CPI 지속 1,500, CPI·SPI 지속 1,725다.
