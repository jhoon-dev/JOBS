# JOBS Project Planner — English store listing

Store display name: JOBS Project Planner. Initial release: free in all supported markets. The application interface currently supports Korean; an English listing does not imply an English application interface.

Short description: Plan project schedules, resources, costs and progress with a desktop Gantt workspace.

JOBS brings project tasks, dependencies and Gantt charts together with resource assignments, calendars, baselines, progress and cost analysis. Organize tasks in a work breakdown structure, calculate schedules, review constraints and compare changes against approved baselines.

Manage multiple project windows and compare shared resource demand. Export schedule, resource and cost reports to Excel or PDF. Import and export supported subsets of Microsoft Project XML and Primavera XER, with explicit diagnostics for unsupported content.

Projects and recovery data stay in local files. JOBS does not require an application account, display advertising, collect usage analytics or provide an application-operated cloud synchronization service. Update behavior follows the installed distribution channel and is described in the privacy policy.

This is an initial release. Validate imported data, scheduling results and exports using copies of your own files before relying on them in an operational workflow. Format conversion does not preserve every field supported by external products.

Features:

- Tasks, WBS, FS/SS/FF/SF dependencies and working-time lags
- Gantt editing, task calendars, date constraints and deadline warnings
- Work-driven schedules, task types, manual splits and resource calendars
- Baselines, progress reporting, comparisons and resource-leveling scenarios
- Planned and actual costs, earned value analysis and Excel/PDF reports
- Multi-project windows, saved workspaces and shared resource demand
- Local storage, automatic recovery, undo and redo

Category: Productivity. No advertising or in-app purchases are implemented.
