# JOBS 개인정보 처리방침

작성일: 2026-10-29. 갱신일: 2026-10-31. 적용 대상: 이 저장소에서 제공하는 JOBS 데스크톱 앱의 현재 버전.

JOBS 앱은 자체 계정, 광고, 사용 분석, 원격 오류 수집 또는 운영자가 관리하는 클라우드 동기화 서비스를 사용하지 않습니다. 앱이 프로젝트 내용을 운영자 서버로 전송하지 않습니다.

앱 시작 시 새 버전을 확인하는 기능은 기본적으로 켜져 있으며 **설정 → 업데이트 → 앱 시작 시 새 버전 확인**에서 해제할 수 있습니다. 일반 배포판은 GitHub의 `jhoon-dev/JOBS` 공개 Release API에 연결하고, 사용자가 다운로드를 선택하면 GitHub의 설치 파일을 내려받습니다. 요청에는 프로젝트 내용·파일 경로·자원·원가 데이터나 계정 토큰을 넣지 않습니다. 일반 HTTP 연결에 필요한 IP 주소 등의 네트워크 정보와 `JOBS-Updater` User-Agent가 GitHub에 전달됩니다. GitHub 측 처리는 GitHub 개인정보 처리방침에 따릅니다.

Microsoft Store판은 Microsoft Store API로 이 앱의 업데이트를 확인하며 설치는 Microsoft Store에서 진행합니다. 해당 통신과 계정 처리는 Microsoft 정책에 따릅니다. 개발용 MSIX는 실제 Store에 연결되지 않은 상태를 안내합니다. 자동 확인을 해제해도 설정에서 사용자가 직접 업데이트 확인을 요청할 수 있습니다.

Mac App Store용 빌드는 앱 자체의 외부 서버 버전 확인이나 설치 파일 다운로드를 사용하지 않습니다. 사용자가 업데이트 버튼을 선택하면 App Store의 이 앱 페이지를 엽니다. App Store의 업데이트·계정·다운로드 처리는 Apple의 정책과 사용자의 macOS 설정에 따릅니다.

사용자가 입력하거나 가져온 프로젝트, 작업, 자원, 비용, 실적 및 보고서는 사용자가 선택한 파일과 앱의 로컬 복구 데이터에 저장됩니다. 자원 이름 등에 개인 정보를 입력할 수 있으므로 파일의 보관 위치와 접근 권한을 사용자가 관리해 주세요. 사용자가 동기화 폴더를 저장 위치로 선택하거나 외부 도구로 파일을 공유하면 해당 서비스의 정책이 적용됩니다.

Microsoft Store/MSIX판은 패키지의 LocalState에 설정과 자동 복구 데이터를 저장합니다. 일반적인 Windows 앱 제거 시 이 앱 상태가 제거됩니다. 사용자가 별도 위치에 저장한 프로젝트·작업 영역·보고서는 앱 제거 후에도 남으며 사용자가 직접 삭제할 수 있습니다. 다른 배포판의 데이터는 자동으로 이전하거나 삭제하지 않습니다.

Microsoft Store의 계정, 구매, 다운로드 및 운영체제의 진단 처리는 Microsoft의 정책과 사용자의 Windows 설정에 따릅니다. 위 설명은 JOBS 앱 자체의 처리에 관한 것입니다.

문의와 결함 신고는 [프로젝트 지원 페이지](https://github.com/jhoon-dev/JOBS/issues)를 이용할 수 있습니다. GitHub의 공개 이슈에 프로젝트 원본이나 개인 정보·기밀 정보를 올리지 마세요. GitHub를 이용할 때는 GitHub의 개인정보 처리방침이 적용됩니다.

앱의 데이터 처리 방식이 바뀌면 이 문서를 갱신합니다. 최종 Store 제출 시 게시자는 계정의 법적 명칭과 연락 창구, 적용 정책의 정확성을 확인합니다.
