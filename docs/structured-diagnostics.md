# 오류·진단 데이터와 표시

2026-10-28 사용자 승인. DIAG-01~04를 구현 전에 확정한다.

예상 가능한 도메인/계산 입력 오류는 stable code와 매개값/관련 ID를 전달한다. `what()`은 표시 언어 계약으로 사용하지 않는다. 계산 진단도 문구 대신 데이터로 구성하며, 원인을 감싼 경우 원래 코드·매개값·대상을 함께 보존한다. 계산 취소는 기존 별도 경로를 유지한다. 파일/편집 경계도 같은 진단을 표시하며 알 수 없는 표준 예외는 내부 오류로 식별하고 원래 내용을 보존한다.

Qt 없는 공통 표시 계층에서 한국어/영문 메시지와 수정 안내를 생성한다. UI와 보고서가 이 표시를 공유하며 기존 한국어 동작을 유지한다. 영문은 진단용 기반이며 전체 앱 메뉴/도움말 번역을 의미하지 않는다. 미등록 코드는 코드와 매개값을 보여 주고 잘못된 형식 문자열이나 HTML로 실행하지 않는다.

관련 작업 선택은 현재 documentId/작업 ID를 확인하고 검색/필터를 해제해 원본 작업을 선택한다. 자원/달력 오류는 관련 ID를 표시하고 가능하면 사용하는 작업과 연결한다. 문서가 닫히거나 변경된 통합 결과의 탐색은 재계산/다시 열기를 안내한다. 거부 테스트는 코드와 대상·불변 상태를 확인하며 표시 문구는 표시 계층 테스트로 분리한다.

`.jobs`와 과거 기준선/실적/시나리오 payload, 계산 정책은 변경하지 않는다. 실제 구현·코드 목록·검증 결과는 후속 절에 기록한다.
