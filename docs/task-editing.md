## 입력과 이력

작업 삽입은 여러 줄 이름을 받아 원본 순서의 현재 작업 앞에 넣는다. 현재 작업이 없으면 프로젝트 끝에 추가한다. WBS 탐색 범위를 기본 소속으로 사용한다. 작업 삭제는 선택 행의 관계/배정/작업 예산을 함께 지우되 승인된 기준선과 시나리오 사본은 유지한다. 선택 중 실적/원가 보고 이력이 있는 작업은 삭제할 수 없다. 삭제 미리보기와 확인을 제공하고 확인 뒤에도 최신 대상/이력 검사를 반복한다.

복제는 프로젝트 원본 순서로 선택 집합을 복사하고 마지막 선택 원본 뒤에 넣는다. 이름에 ` (복사)`를 붙인다. 작업의 달력/제약/공수/중단/WBS·배정·예산은 복사한다. 집합 내부 선행/관계 속성은 복제 ID로 연결하고 외부 선행 ID는 유지한다. 원장과 승인 기록은 복사하지 않는다. 복사한 제약·자원 부하는 일반 계획과 같이 후속 계산에서 진단한다.

각 작업은 사본에서 전체 검증한 뒤 기존 Document 이력에 한 번만 반영한다. 일반 입력의 기존 undo 상한(100개/32 MiB), 단조 증가 revision과 계산 STALE, 승인·제출 불변 경계를 유지한다. 고정 공수 기간 변경은 기존 배정률 역산을 유지한다. 여러 작업 붙여넣기는 이름/관계와 기간 제안값을 먼저 사본에 구성한다. 고정 단위의 기간 입력 전환을 적용하고, 고정 공수의 배정률 역산은 프로젝트 원본 순서로 수행한다. 같은 붙여넣기에서 미정 기간을 채우는 변경도 역산 전에 반영한다. 하나라도 실패하면 전부 거절한다.

## 표와 클립보드

표는 확장 다중 선택을 지원한다. 행 머리글/Shift/Ctrl 선택은 여러 행, 셀 드래그는 직사각형을 선택한다. 복사할 때 불연속/구멍 난 셀 범위를 거절한다. 전체 행 선택은 편집 가능한 이름·기간·선행 3열을 복사하고, 일반 직사각형은 보이는 선택 열의 표시 값을 복사한다. 탭/줄바꿈/따옴표가 있는 값은 TSV 인용부호로 escape한다.

붙여넣기는 현재 셀에서 시작하여 보이는 행 순서로 적용한다. 이름/기간/선행 3열만 입력 가능하다. 선행 번호는 정렬된 화면 행이 아니라 프로젝트 원본 번호이며, 붙여넣기 전 스냅샷에서 stable ID로 변환한다. 빈 기간은 미정, 0은 마일스톤, 빈 선행은 관계 제거다. 이름은 빈칸을 허용하지 않는다. 행 확장은 이번 범위가 아니며 새 행은 Insert로 먼저 만든다. 오류는 상대 붙여넣기 행/열과 이유를 알리고 원자적으로 실패한다. TSV 4 MiB·1만 행·3만 셀 한도를 검사한다. 내부 복사도 원본 번호 의미를 사용하며 다른 문서에 붙이면 대상 문서의 번호를 의미한다.

## 보기와 선택

검색/필터/정렬은 프로젝트 입력과 별도인 창 상태다. WBS 범위와 함께 적용하지만 보고서와 계산은 계속 전체 프로젝트/선택 WBS의 기존 계약을 따른다. 표시 수를 별도로 알린다. 계획 임계 필터는 최신 유효 계획 결과에서만 판정하고 예측/미계산 때 결과 없음과 계산 필요를 알린다. 정렬의 미정은 양방향 모두 뒤, 동률은 원본 순서다. 표/간트의 표시 순서와 현재 작업 ID를 맞추며 숨긴 선택은 조작 대상에서 제외한다.

단일 작업 대화상자는 현재 셀의 작업, 다중 삭제/복제는 선택된 보이는 행 전체를 사용한다. 보기를 바꿔도 남아 있는 선택 ID/현재 열을 유지한다. 삽입/복제 후 생성 ID를 선택하되 검색/필터로 숨겨지면 표시 수/상태로 알린다. 문서 교체 시 보기와 선택을 초기화한다.

## 구현과 검증

정렬/필터 뒤 선행·배정 ID, 부분 실패/읽기 전용/순환·미정과 고정 공수의 일괄 편집, 삭제 보호/참조 정리·복제 내부/외부 관계, 한 번 undo/redo·저장/복구를 도메인 시험으로 검사한다. Qt UI는 실제 클립보드와 키보드·선택·삭제 확인·검색/정렬·간트 순서·읽기 전용을 검사한다. 기존 일정/원장/출력과 1천/1만 성능 회귀를 유지한다. 아래 사용법과 증거를 따른다.


편집 메뉴의 **작업 삽입**에서 한 줄에 한 작업 이름을 입력한다. 선택 행의 원본 순서 앞에 넣으며, 선택이 없으면 끝에 추가한다. **선택 작업 복제**와 **선택 작업 삭제**는 표의 선택 행 전체를 대상으로 한다. 원장 이력이 있는 작업은 이름을 바꾸거나 계획을 편집할 수 있지만 삭제할 수 없다. 삭제는 작업/관계/배정/예산 수를 확인하고, 확인 중 문서가 바뀌면 다시 선택해야 한다.

복사/붙여넣기/전체 선택/검색은 OS 표준 키를 사용한다(Windows의 Ctrl, macOS의 Command). 표에서 Insert는 삽입, Delete는 선택 작업 삭제, Ctrl+D 표기는 Qt의 네이티브 메뉴 단축키를 따른다. F2는 현재 셀 편집, Tab은 다음 셀, Esc는 현재 셀 초안을 취소한다. 셀 편집기 안의 복사/붙여넣기·Delete는 글자 편집으로 처리한다. 기존 끝에 한 작업 추가는 Ctrl+Shift+Insert로 변경했다. 검색은 180ms 입력 지연 후 갱신하고 보기 초기화로 검색/필터/정렬을 함께 해제한다. 열 제목 중 이름/기간/시작일을 눌러도 정렬할 수 있다.

`task_editing_contract`는 내부/외부 관계와 설정을 보존하는 복제, 삭제 참조 정리·원장 보호, 한 번 undo/redo, 오류 시 불변, 미정 기간 보완을 포함한 고정 공수 역산, 읽기 전용·저장/재열기·체크포인트 복구를 검사한다. `task_editing_ui`는 실제 클립보드/TSV 인용·빈칸/한도, 정렬 후 원본 ID를 대상으로 한 일괄 붙여넣기, 행/열 오류와 한 번 undo, 검색/마일스톤/임계/미정 정렬·표/간트 순서, 모달 취소/확인·키보드 삽입/복제/삭제·F2/셀 초안·읽기 전용을 검사한다. 네이티브 시험은 원래 클립보드 MIME 데이터를 시험 종료 때 복원한다.

로컬 Release 전체 **28/28 CTest**, Windows 네이티브 새 UI, XLSX 5개/PDF 6개 독립 reader 검사를 통과했다. 기존 충돌 진단의 작업 이동도 새 선택 모델에 맞게 현재 ID 하나를 선택하도록 유지했다. 입력 파일 schema 9와 기존 기준선/실적/원가/시나리오 원장은 그대로 사용한다. Windows/MSVC·macOS CI는 같은 회귀 및 1천/1만 고정 입력 성능·전체 일정 해시 검사를 실행한다.

자동 새 행 확장, 여러 작업의 속성 대화상자, Gantt 다중 막대 강조/이동, 모델 기반 표 전환은 후속 범위다. 현재 간트는 현재 작업을 강조하고, 여러 선택 행은 표에서 표시한다. 고정 공수 기간을 많이 바꾸면 각 작업의 전체 계획 역산을 원본 순서대로 수행하므로 대용량 역산 붙여넣기의 지연/취소는 별도 후속 검증이다. 보기 필터는 보고서 범위나 전체 계산을 줄이지 않는다.


CI의 `scripts/capture-task-editing-ui.py build`는 표 정렬·선택·계산을 구성한 뒤 앱 자신의 위젯만 네이티브 PNG로 저장한다. 데스크톱 입력을 전송하지 않으며 `task-editing-ui-Windows`, `task-editing-ui-macOS` artifact로 보존한다. 이 화면 증거와 Qt offscreen 상호작용 회귀를 구분한다. 로컬 전체 Windows 키보드/클립보드 UI 시험은 `build/jobs_task_editing_ui_tests.exe -platform windows`다.
